# Wayza skill for OpenClaw

`wayza/` is the skill folder as it goes to ClawHub: `SKILL.md` and a dependency-free Node script. Not published:
it goes to ClawHub on launch day, with `@wayza/agents` on npm (Graham, 2 Oct 2026).

Test: `node --no-warnings packages/openclaw-wayza/test/skill.test.mjs` runs the script against a real core over HTTP.
